## Дополнить макет страницы:
<ul>
  <li>Flexbox: навигационное меню (горизонтальное, адаптивное) и карточки (3–4 шт.) в ряд.</li>
  <li>Grid: галерея/дашборд (2–3 колонки, 2–3 строки).</li>

</ul>

## Вариант 6. Тема «Любитель кино и сериалов».
Flex-карточки: «Топ-фильмов для просмотра» (название, жанр, год, постер миниатюрный). Grid-галерея:
«Любимые режиссёры» (фото, имя, 1 знаковый фильм – сетка 2×2). Адаптивность: карточки
на мобильном – 1 колонка, планшет – 2, десктоп – 3; Grid на мобильном – 1 колонка, на
остальных – 2 колонки. Используйте "figure" + "figcaption" для фото режиссёров.
